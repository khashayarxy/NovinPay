# NovinPay

وب‌سایت رسمی **NovinPay**؛ کسب‌وکار فروش و تعمیر دستگاه‌های کارتخوان (POS) در شهریار. این نسخه شامل پایهٔ وب‌سایت عمومی (زبان فارسی، چیدمان کامل RTL) و **پنل مدیریت محصولات** (فاز دوم) است: احراز هویت تک‌مدیره، CRUD محصولات و بارگذاری امن تصویر.

## فناوری‌ها

- Laravel 13 با PHP 8.4.1 یا بالاتر (مطابق وابستگی‌های قفل‌شده)
- Blade + HTML/CSS/JavaScript
- Tailwind CSS v4 (از طریق Vite) — از قبل در اسکلت پروژه پیکربندی شده است
- PHPUnit
- پایگاه دادهٔ توسعه: SQLite — پایگاه دادهٔ تولید پیشنهادی: MySQL/MariaDB

## راه‌اندازی

```bash
composer install
cp .env.example .env        # در صورت نیاز
php artisan key:generate
touch database/database.sqlite
php artisan migrate
php artisan test             # اجرای تست‌ها
npm install
npm run build               # یا npm run dev برای توسعه
php artisan serve
```

## پنل مدیریت

مرز دسترسی فاز Foundation فقط حساب ذخیره‌شدهٔ منطبق با `ADMIN_EMAIL` را مجاز می‌کند؛ کاربران عادی حتی با ورود معتبر به مسیرهای مدیریت محصولات دسترسی ندارند. مقدار خالی یا نامعتبر باعث رد دسترسی می‌شود. برای حساب مدیر موجود نیازی به اجرای مجدد Seeder یا تغییر دیتابیس نیست. جزئیات، تست و بازگشت تغییرات در [docs/FOUNDATION.md](docs/FOUNDATION.md) آمده است.

- آدرس ورود: `/admin/login` — ثبت‌نام عمومی وجود ندارد؛ فقط از طریق تک‌حساب مدیر.
- پیش از استفاده، ایمیل و گذرواژهٔ مدیر را در `.env` (متغیرهای `ADMIN_EMAIL` و `ADMIN_PASSWORD`، حداقل ۸ نویسه) وارد کنید و سپس:

```bash
php artisan db:seed --class=AdminUserSeeder
```

- امکانات: ایجاد/ویرایش/حذف محصول، انتشار/پیش‌نویس، مشخصات فنی (برچسب/مقدار)، بارگذاری و جایگزینی تصویر (JPEG/PNG/WebP تا ۲ مگابایت) با حذف امن فایل‌های قبلی.
- مسیرهای مدیریت محصولات پشت `auth` و Gate با نام `access-admin` هستند؛ لاگین دارای محدودیت نرخ با پیام فارسی است: ۵ تلاش ناموفق برای هر ایمیل و ۳۰ تلاش برای هر IP در دقیقه (سقف IP با متغیر `ADMIN_LOGIN_IP_MAX_ATTEMPTS` در `.env` و از طریق `config/admin.php` قابل تغییر است).
- ساخت مدیر از `config('admin.email')` / `config('admin.password')` خوانده می‌شود (نه `env()` مستقیم)، بنابراین بعد از `php artisan config:cache` هم کار می‌کند.
- تصاویر روی دیسک `public` و در `storage/app/public/products/` ذخیره می‌شوند (در گیت نادیده گرفته می‌شوند)؛ در محیط توسعه `php artisan storage:link` لازم است. راهنمای کامل استقرار در `docs/DEPLOYMENT.md` است.

## داده‌های نمونه

کاتالوگ روی یک نصب تازه **خالی** است و حالت «هنوز محصولی ثبت نشده است» را نمایش می‌دهد. برای مشاهدهٔ کارت محصولات در محیط توسعه:

```bash
php artisan db:seed --class=SampleProductSeeder
```

تمامی رکوردهای این Seeder با `is_sample = true` ثبت می‌شوند و در رابط کاربری با نشان «داده نمونه» نمایش داده می‌شوند. این Seeder عمداً در `DatabaseSeeder` فراخوانی نمی‌شود.

## پایگاه داده

- **توسعه (موقت):** SQLite (`database/database.sqlite`) — در محیط فعلی سرور MySQL/MariaDB در دسترس نیست.
- **تولید (هدف):** MySQL یا MariaDB. پیش از استقرار باید `DB_CONNECTION` و اعتبارنامه‌های دیتابیس در `.env` تنظیم شوند.
- سازگاری با MySQL واقعی **آزموده شد** (MySQL 8.0.46 با `utf8mb4_unicode_ci`): همهٔ migrationها (شامل backfill جستجو) و کل ۱۲۳ تست (۴۶۱ assertion) روی MySQL سبز بودند. ستون JSON برای `specifications`، ایندکس یکتای `slug`، ستون `boolean` با مقدار پیش‌فرض و `like` در جستجو همگی سازگارند.
- **جستجو نرمال‌سازی می‌شود:** ارقام فارسی/عربی به ASCII، حروف `ي/ك` به `ی/ک`، حذف نیم‌فاصلهٔ مخفی (ZWNJ) و فشردن فاصله‌های تکراری انجام می‌شود تا جستجو با هر variant کارا باشد؛ کاراکترهای `%`/`_` نیز در ورودی کاربر به‌صورت تحت‌اللفظی match می‌شوند (wildcard نیستند). در ستون مشتق `search_text` ذخیره می‌شود و متن نمایشی دست نمی‌خورد.

هیچ `.env` واقعی نباید متعهد (commit) شود؛ فقط `.env.example` بدون رمز عبور.

## صفحات پیاده‌سازی‌شده

| مسیر | توضیح |
| --- | --- |
| `/` | معرفی، خدمات، محصولات شاخص، فراخوانی اقدام |
| `/products` | فهرست محصولات + جستجو + فیلتر دسته‌بندی + حالت خالی |
| `/products/{slug}` | جزئیات محصول (توضیحات، مشخصات، قیمت، موجودی، نو/کارکرده) |
| `/services` | توضیح خدمات فروش و تعمیر |
| `/repair` | روند تعمیر، کد پیگیری، پیش‌نمایش فرم آنلاین (به‌زودی) |
| `/contact` | اطلاعات تماس رسمی، تلفن قابل کلیک، ساعات کاری و پیوندهای مسیریابی |
| `/terms`، `/privacy` | ساختار صفحات حقوقی بدون ادعای نهایی |
| `/admin/login` | ورود مدیر (بدون ثبت‌نام عمومی) |
| `/admin/products` | فهرست/ایجاد/ویرایش/حذف محصولات (پشت احراز هویت) |
