## Mobile number fields

| Surface | Field | Display |
| --- | --- | --- |
| Customer login, registration and OTP recovery | Account mobile | Persian digits with phone autofill and a phone keypad. |
| Customer profile | Registered mobile | Persian digits in the read-only field. |
| Customer address book and shipping addresses used at checkout | Recipient mobile on create and edit | Persian placeholder and prefilled number. Checkout itself uses the signed-in account and saved addresses. |
| Online repair request | Registered mobile | Persian digits in the read-only field. |
| Public repair tracking | Registered mobile | Persian placeholder and entered digits. |
| Public consultation | Contact mobile | Persian placeholder and entered digits. |
| Admin customer create and edit | Contact mobile | Persian digits in editable and prefilled values. |
| Admin repair intake | Contact mobile | Persian digits in editable and prefilled values. |
| Admin consultation list | Exact mobile search | Persian digits with search autofill disabled. |
| Support widget | Contact editing, optional contact prompt and mobile recovery | Persian digits for typing and session prefills. Outbound chat requests use ASCII digits. |

The shared formatter preserves leading zeros and keeps phone strings left-to-right inside RTL forms. Native form payloads use ASCII digits where the browser supports the form-data event. Server-side normalization continues to protect submissions from older browsers and direct requests.

The online form shows one description field with the original 10–2,000 character limits. Historical submissions already store both descriptions together in the encrypted issue field. Staff can still read that field, and a customer submitting an older form already open in their browser can still submit both values.

Privacy, legal wording, payment obligations, provider settings, and owner-approved commercial claims were retained. In particular, the checkout copy still places payment after stock confirmation and selection of the delivery method.
