## Acceptance gate

After preparing the isolated acceptance fixture and building the candidate, run `scripts/local/verify-herd-checkout.ps1 -ExpectedCommit <full SHA>`. It checks the actual HTTPS link, clean source checkout, and the bytes of the rendered Vite assets and shared navigation files. Record its result along with feature browser evidence and exact-commit CI. A dirty or different linked checkout is a development preview. The script performs read-only HTTP and Git checks; it does not update the Herd link or the database.
